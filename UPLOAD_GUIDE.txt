IMPORTANT: CLAIMS AND PROFESSIONAL SCOPE
=======================================
The directory describes topics that can be considered or scoped. It does not
mean SPEDAR already has in-house capacity for every field. Core/current-team
aligned topics are tagged "Team capability" and professional specialist
fields are tagged "Specialist scoping". Specialist fees, licenses, registration,
appointment, technical equipment, insurance, permissions and sign-off must be
verified for each assignment. No competitor's projects, client logos,
certifications, counts or awards are attributed to SPEDAR.

GITHUB WEB UPLOAD PROCEDURE (NO COMMAND LINE)
=============================================
1. Download and EXTRACT this ZIP. DO NOT upload the ZIP itself.
2. Open https://github.com/spedarconsultantsltd/spedarconsultantsltd.github.io
3. Code > Add file > Upload files.
4. Drag the 9 ROOT files above into the repository ROOT and Commit changes.
5. Open assets/css in the GitHub repository > Add file > Upload files.
   Upload spedar-enrich.css and spedar-pro.css, then Commit.
6. Open assets/js in the GitHub repository > Add file > Upload files.
   Upload site-config.js, spedar-enrich.js, spedar-data.js,

7. Wait for the GitHub Pages workflow to succeed; then hard refresh Ctrl+Shift+R.

into multiple ZIPs for the GitHub 100-file browser upload limit.
